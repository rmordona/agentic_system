# spec.md - Event Planning

## 1. Event Overview
- Event Name: Annual Tech Conference 2026
- Purpose: Gather industry leaders to share insights
- Organizer: TechOrg Inc.
- Target Audience: Developers, Product Managers, Executives

## 2. Objectives & Goals
- Host 500+ attendees
- Provide 20+ tech talks and workshops
- Facilitate networking opportunities
- Generate 100 new leads for sponsors

## 3. Functional Requirements
- Online registration system with automated confirmations
- Ticketing system with QR code check-in
- Schedule with speaker info accessible via app
- Real-time notifications for schedule changes

## 4. Non-Functional Requirements
- Venue must support WiFi for all attendees
- Event app must handle 500 concurrent users
- Ensure accessibility for differently-abled attendees
- Backup plan for weather or technical disruptions

## 5. User Stories / Use Cases
- "As an attendee, I can register online and receive a confirmation email."
- "As a speaker, I can submit my presentation slides ahead of time."

## 6. Logistics & Venue Details
- Venue: Tech Convention Center, Main Hall & Breakout Rooms
- Dates: June 12-14, 2026
- Catering: Vegan and non-vegan options
- Accommodation: Partnered hotels for discounted rates

## 7. Roles & Responsibilities
- Event Manager: Oversees entire event
- Registration Team: Handles attendee check-in
- AV Team: Manages sound, projection, and live streaming

## 8. Dependencies & Integrations
- Third-party ticketing platform
- Payment processor for ticket sales
- CRM integration for attendee tracking

## 9. Constraints & Assumptions
- Budget: $100,000 total
- Speakers confirmed 3 months before event
- All attendees provide valid identification for security

## 10. Acceptance Criteria
- 500+ attendees successfully registered
- All scheduled sessions conducted on time
- Event feedback score > 90% satisfaction

## 11. Risks & Mitigations
- Risk: Speaker cancellation → Mitigation: Have backup speakers
- Risk: Venue power failure → Mitigation: Backup generators on standby

## 12. Glossary / Definitions
- Attendee: Registered participant
- Sponsor: Company supporting the event financially
- Session: Individual talk or workshop
